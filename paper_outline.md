## IV. Methodology
### A. Data and partitioning
UNSW-NB15 (train/test files), ToN_IoT; 4 non-IID (Dirichlet) device partitions; **Fuzzers held out** from central pretraining and from devices 2-4 as the zero-day-style class; official test set 82,332 rows (6,062 Fuzzers); ToN_IoT held-out 31,656 rows. Canonical schema: 5 continuous (duration, src_bytes, dst_bytes, src_pkts, dst_pkts) + 3 categorical (proto, service, state).
### B. Model
Tabular Transformer: d_model=32, 4 heads, 2 layers, FFN 128, 4 tokens/flow (continuous block + proto + service + state), mean-pool, linear head.
### C. LoRA federation
Formulas (see Section X below). LoRA r=4, alpha=8 on both FFN linears per layer; head fully trained; adapter payload 14.67 KB on the wire.
### D. FedAvg aggregation
Sample-weighted average; quorum = 4 devices or 30 s timeout with >=1 participant (disclose that straggler rule: with a strong backbone only the device holding the rare class has reason to update).
### E. Edge agent policy
Decision rules: BLOCK if predicted malicious and confidence >= 0.9; ALERT if malicious below 0.9; RETRAIN if sliding-window mean confidence (window 50, min 20) < 0.6 or local self-eval accuracy < 0.90; SYNC every 15 s.
### F. Local retraining
FIXED 5 epochs x 20 steps, batch 64, Adam lr 1e-3; hard-example sampling with clipped loss weights; FGSM contrastive adversarial term (epsilon 0.05).
### G. Explainability
Attention rollout over the 4 tokens; heuristic attribution, not causal (say so).
### H. Live capture bridge
Packet sniffing -> flow records -> canonical schema (scapy, 5-tuple flows, flush on RST/FIN or 2 s idle).

## VII. Discussion
- Where the system wins: lower FPR than the pooled centralized baselines at similar/higher accuracy; 14.67 KB payload.
- Honest tradeoffs: FPR rises after federated rounds; Fuzzers recall of centralized (78-87%) is higher than federated, as expected when trained on the class directly.
- Why UNSW-NB15 (87%) is below the synopsis target (>96%) and ToN_IoT is above: dataset difficulty and the held-out-class design; the 97.5% central validation accuracy is on the pretraining pool and is not a test result.
- Explainability: what the rollout shows, and the limit of the claim.

## VIII. Limitations and Threats to Validity
- Single backbone training run for Table I (unseeded); only 4 federated seeds.
- Simulated federation experiment (moto-mocked cloud) vs live deployment: say which table came from which.
- Flow-level features from CSV datasets; live capture tested only on loopback nmap scans, not validated against labeled traffic.
- No adversarial-robustness evaluation despite the FGSM term.
- Python 3.9 / peft-version issue found during deployment (state-dict key mismatch) and fixed by reading/writing trainable parameters directly.
- Alert-fatigue risk from higher FPR.

## X. Formulas to include (from the code)

1. Flow encoding: continuous features standardized with the stored scaler, $x_c' = (x_c-\mu)/\sigma$; categorical via vocabulary embeddings.
2. Token sequence: $S = [\,W_c x_c' ;\; E_{proto}[p];\; E_{svc}[s];\; E_{state}[t]\,] \in \mathbb{R}^{4\times d}$, $d=32$.
3. Self-attention: $\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\!\left(QK^\top/\sqrt{d_k}\right)V$.
4. Classifier: $\hat y = \mathrm{softmax}\big(W_h\cdot\tfrac{1}{4}\sum_{i=1}^{4} z_i + b_h\big)$.
5. LoRA: $W' = W_0 + \tfrac{\alpha}{r}BA$, $A\in\mathbb{R}^{r\times d_{in}}$, $B\in\mathbb{R}^{d_{out}\times r}$, $r=4$, $\alpha=8$ ($B$ zero-initialized).
6. FedAvg: $\theta^{t+1}=\sum_{k=1}^{K}\frac{n_k}{n}\theta_k^{t}$, $n=\sum_k n_k$ (applied per named adapter tensor).
7. FGSM perturbation: $x_{adv}=x+\epsilon\,\mathrm{sign}(\nabla_x \mathcal{L}(f(x),y))$, $\epsilon=0.05$ on the continuous block.
8. Local loss: $\mathcal{L}=\mathcal{L}_{CE}(x,y)+\mathcal{L}_{CE}(x_{adv},y)$.
9. Hard-example sampling weight: $w_i=\min(\ell_i,3.0)+0.3$, $\ell_i$ = current CE loss of sample $i$.
10. Drift trigger: $\frac{1}{|W|}\sum_{c\in W}c<\tau_c$ with $|W|=50$, $\tau_c=0.6$ (after at least 20 samples); self-eval trigger: $\mathrm{acc}_{local}<0.90$.
11. Decision rule: BLOCK if $\hat y=1\wedge c\ge0.9$; ALERT if $\hat y=1\wedge c<0.9$.
12. Attention rollout: $\hat A_l = \mathrm{norm}(0.5A_l+0.5I)$, $R=\hat A_L\cdots\hat A_1$, importance$_j=\sum_i R_{ij}/\sum_{ij}R_{ij}$ (Abnar & Zuidema 2020).
13. Metrics: Accuracy $=\frac{TP+TN}{TP+TN+FP+FN}$; Precision $=\frac{TP}{TP+FP}$; Recall $=\frac{TP}{TP+FN}$; FPR $=\frac{FP}{FP+TN}$; Macro-F1 $=\frac12(F1_{normal}+F1_{attack})$.
14. Drift Recovery Index (our proxy, not Vijetha's): $\mathrm{DRI}=\frac{r_{after}-r_{before}}{1-r_{before}}$.
15. Payload: bytes of the JSON/base64 adapter upload (14,914 B -> 15,026 B after the state-dict fix).
